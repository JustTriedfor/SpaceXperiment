Imitation pipeline

        
Builds a network that already knows how to land: the scripted expert flies and is recorded, a network is cloned from it, then DAgger rounds let the network fly while the expert labels every state it visits, and the best round is saved as <name>_final and evaluated.
          For Dual land there is one expert per lander (they start on the same path, so they land together). One network = the 512 × 512 dual network flying both landers. Two networks = a pair: each lander's own view and actions go to its own data set, and each network is cloned and DAgger-retrained on its own data (files <name>_clone_A/_B, ...; the pair is addressed by its base name). Either can start as copies of a single-lander checkpoint. Everything it makes is named after the pipeline (checkpoints <name>_clone, <name>_dagger_N, <name>_final; data <name>_expert, <name>_dagger_N). Roughly: demonstrations 1 min, cloning 2-5 min, 10-15 min per DAgger round. Tip: a dual network that starts as two copies of a good single-lander checkpoint already flies like it, so for that start you can untick clone and go straight to DAgger (cloning on little data can only make it worse).

Checkpoints 

        
Every saved network. single = one lander (18 inputs, 5 outputs), dual land = ONE network flying both Dual land landers (40 inputs, 10 outputs, twice as wide), two networks = a pair, one network per lander (name_A and name_B, each 40 inputs, 5 outputs, shown as one row). The exploration noise is what PPO adds to every action (default 0.2); a cloned policy that lands cleanly can fail with it, so make a quiet copy before continuing with PPO. Click a row to select it.

Pair of networks (single checkpoints only): two separate files <name>_A and <name>_B, each a copy of the single network with zero weight on the 22 inputs that describe the partner. Train them with the pair start profile: each lander then has its own network, critic and reward. Dual copy (single checkpoints only): two copies of the network side by side, 512 × 512, with zero weight on the four extra inputs - it lands both landers exactly like the single one, and PPO then learns to use the extra inputs to land together. Move to trash moves the file to models/_trash; nothing is deleted for good.

Step rows: what the lander saw (o0.. - 18 values for one lander, 40 for Dual land), what it did (a0.. - 5 or 10 actions), the scaled reward, and the episode outcome. The size is read from the data itself. Data is kept for every 10th episode plus the best and worst 5%; the oldest chunks are deleted when the budget is full.
